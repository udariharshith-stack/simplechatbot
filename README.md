# 🤖 Smart AI Chatbot

A Smart AI Chatbot built using Python and Tkinter with human-like responses, GUI interface, dark mode, calculator support, jokes, and website opening features.

---

## 🚀 Features

- 💬 Human-like chatbot responses
- 🖥️ GUI Chat Window using Tkinter
- 🌙 Dark Mode / Light Mode
- 🧮 Calculator support
- 😂 Random jokes
- 📅 Current date and time
- 🌐 Open Google, YouTube, ChatGPT
- 🧠 Smart AI-style replies
- ⌨️ Enter key support
- 🗑️ Clear chat option

---

## 🛠️ Technologies Used

- Python
- Tkinter
- Datetime
- Random
- Webbrowser
